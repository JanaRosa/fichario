# Roadmap — Fichário

## Fase 0 — Fundação
- [x] Criar repositório
- [x] Definir público inicial e visão de expansão
- [x] Definir arquitetura inicial
- [ ] Criar identidade visual e protótipo navegável
- [ ] Configurar ambiente de desenvolvimento

## Fase 1 — MVP pessoal
- [ ] Painel inicial
- [ ] Cadastro de concurso, edital, disciplinas e assuntos

- [ ] Resolver questões e registrar tentativas
- [ ] Caderno de erros

- [ ] Flashcards e revisão espaçada básica
- [ ] Indicadores de desempenho

## Fase 2 — Preparação completa
- [ ] Simulados com cronômetro
- [ ] Histórico detalhado

## Fase 3 — Multiusuário
- [ ] Cadastro e autenticação
- [ ] Isolamento de dados por usuário (RLS)
- [ ] Preferências e perfis
- [ ] Limites e monitoramento de custos de IA
- [ ] Termos, privacidade e fluxo LGPD

## Fase 4 — Comunidade e evolução
- [ ] Desafios privados e públicos
- [ ] Ranking opt-in
- [ ] Compartilhamento de fichários
- [ ] Planos e pagamentos, se fizer sentido

## Critério de conclusão do MVP
Uma pessoa consegue cadastrar seu concurso e assuntos, responder questões, entender erros, revisar conteúdos e visualizar sua evolução com os dados persistidos com segurança.
